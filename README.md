本课题研究基于SpringBoot框架的住房租赁服务平台的设计与实现，是软件工程在房地产行业信息化中的具体应用，为的是解决传统住房租赁市场中信息不对称、管理效率低、交易流程繁琐等问题，构建高效透明的数字化平台。本系统主要是为租赁双方提供标准化信息发布与匹配渠道，提升交易效率；后台管理功能增强信息监管与数据分析能力。前端采用Vue.js渐进式框架及Element UI组件库构建用户界面，实现响应式交互与组件化开发，提升了系统的用户体验与开发维护效率。本系统验证了现代Web技术解决传统行业痛点的可行性，为住房租赁服务数字化转型升级提供了可行的技术解决方案。本课题研究方法遵循软件工程规范，采用了B/S架构与分层设计模式，运用用例分析、实体关系建模等方法进行系统开发。实现了一个功能完备、运行稳定的系统原型。

项目采用前后端分离式开发,有AI Coding Assistant Lingma(现在叫Qoder)辅助开发。

该库为课程设计项目后端部分。

开发环境：
Java、Springboot框架、Maven、MySQL
